WallyGuard patch provenance

This directory contains patch artifacts from WallyGuard bug-discovery campaigns
and patches corresponding to associated CORE-V Wally pull requests.

The five reconstructed files use the exact upstream PR code diffs, reformatted
to match the bare git-diff style of the recovered WallyGuard patch files. Their
original local WallyGuard run artifacts were lost and their original run IDs are
therefore not invented here.

Other files in this directory
-----------------------------

The directory also contains archived WallyGuard candidate patch exports and other
campaign-level discovery artifacts. These should not be assumed to have a
one-to-one relationship with the seven upstream pull requests.

Historical controller statuses remain unchanged. In particular, archived
successful targeted repairs recorded as `candidate_fix_verified` are not
retroactively relabelled as `confirmed`.
