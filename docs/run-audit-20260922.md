## Changes

- `orchestration/derived_configs.py`, called from `make_worktree()` under its
  lock: generate configurations in an isolated copy of tracked baseline inputs,
  check completion, then install before agent snapshots. Hash both inputs and
  outputs to reuse unchanged configurations. Generation/installation failures
  block startup; a failed installation restores previous outputs. No agent is
  allowed to change configurations, and the artifact guard remains active.
- `orchestration/isa_compatibility.py`, called from the shared preflight: require
  explicit configurations and check XLEN, F/D and Zfinx. Unresolved literals and
  parameter/define overrides fail closed. This is not complete ISA equivalence;
  other extensions, privilege and architectural assumptions still need review.
- `orchestration/test_preflight.py`: classify a failure record containing equal
  expected/actual values as `TEST_INVALID`, with precise register-layout feedback.
  Real tool errors still take precedence; no mismatch acceptance gate was relaxed.
- `loop.py` prompts: verify rule preconditions, permit disproving a hypothesis,
  prohibit switching oracle ISA to force a mismatch, explain the self-check
  layout, and leave configuration generation to the controller.
- `.gitignore`: remove the trailing rule that overrode the existing exception
  for controller unit tests. Existing tests and new regression tests are visible
  to Git again. No commit or push was performed.

## Remaining performance issue

The Architect in `181801Z-e71afe58` took 4,202.5 s (70.0 minutes) and executed
171 commands. Recorded command execution was 142.7 s; assistant non-tool time
was 4,073.1 s, including provider/CLI waits rather than measurable pure token
generation. Its advisory exploration budget did not prevent excessive work.
Fixing configuration preparation avoids this specific compilation/guard failure,
but does not demonstrate a 15–35 minute iteration. The next performance change
should address the repeated Architect budget extensions and handoff behavior,
using these traces, while preserving an explicit path for difficult cases.
